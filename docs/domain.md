# 领域说明

家庭财富规划将购房、教育、养老和应急资金视为期限与优先级不同的目标。账户中的现金、证券批次、待交收资金和定期投入共同影响可用资源，税务属性与交易限制则决定调整方案能否执行。方案版本需要保存采用的假设，便于顾问解释目标缺口和资产变动。

`reference/domain.json` 保存可公开的示例枚举与精度约定。正式业务记录应使用稳定标识，并区分业务发生时间、系统接收时间和记录版本。

## 核心概念

- **目标（Goal）**：有金额、到期日、优先级（1 最高）与归属账户；24 个月内为近期目标，触发降险与现金筹集，远期目标只做到期测算。
- **账户（Account）**：税务属性分为应税 / 递延 / 免税，决定卖出时的资本利得税计提与变现顺序。
- **持仓批次（HoldingLot）**：禁售批次（`locked` + 解锁日）、待交收批次（`pending_settlement` + 交收日）与客户锁定资产（`client_locked`）不得被建议绕过。
- **定投（RecurringInvestment）**：按周期投入，在目标到期测算中计终值。
- **临时支出（TemporaryExpense）**：显式归属目标的计入目标测算；未归属的在方案层面从可投资现金扣减，避免重复计算。
- **漂移带（drift_band）**：长期配置权重偏离目标超过带宽才调仓，带内不动。

## 方案与版本

每次创建或调整假设都生成不可变版本（父版本链可追溯）。调整假设返回受影响目标报告：只有缺口、达成率或状态发生变化的目标需要顾问复核。客户确认的版本标记 `confirmed`，重复确认返回 409。

## 金额与精度

金额内部使用 `Decimal`，接口输出保留两位小数；份额数量支持四位小数。交易日历与费率均为示例数据，可按市场与机构实际替换。
